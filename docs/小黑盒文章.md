# 给 dsh 装上长期记忆：dsh-hindsight-local 小白教程（v0.1.2）

![dsh Hindsight 本地记忆插件](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.4/docs/images/cover.png)

## 第一步：打开你的 dsh

我用的是 web 版的（特地独立装了一个干净的），桌面版也一样。

![dsh 主界面](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.4/docs/images/01-dsh%E4%B8%BB%E7%95%8C%E9%9D%A2.png)

## 第二步：准备一个硅基流动的密钥

插件需要两个“帮手模型”：一个**理解文字**，一个给找回来的记忆**排序**。我选的是硅基流动，两个都免费，而且**一个密钥就够了**。

- 理解文字的模型：硅基流动 `BAAI/bge-m3`
- 排序的模型：硅基流动 `BAAI/bge-reranker-v2-m3`

1. 打开 [https://cloud.siliconflow.cn](https://cloud.siliconflow.cn)，注册 / 登录。

   ![硅基流动登录](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.4/docs/images/02-%E7%A1%85%E5%9F%BA%E6%B5%81%E5%8A%A8%E7%99%BB%E5%BD%95.png)

2. 这两个模型都是免费的，不用额外开通：

   ![bge-m3 免费](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.4/docs/images/03-bge-m3%E5%85%8D%E8%B4%B9.png)
   ![bge-reranker 免费](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.4/docs/images/04-bge-reranker%E5%85%8D%E8%B4%B9.png)

3. 左边点「API 密钥」：

   ![API 密钥入口](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.4/docs/images/06-API%E5%AF%86%E9%92%A5%E5%85%A5%E5%8F%A3.png)

4. 点「新建 API 密钥」，描述随便写，点「新建密钥」：

   ![新建密钥](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.4/docs/images/07-%E6%96%B0%E5%BB%BA%E5%AF%86%E9%92%A5.png)
   ![创建成功](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.4/docs/images/08-%E5%AF%86%E9%92%A5%E5%88%9B%E5%BB%BA%E6%88%90%E5%8A%9F.png)

5. 点一下密钥那一栏就复制好了（也许需要先实名认证，我认证过了）。**复制好后先存起来，后面马上要用。**

   ![点击复制](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.4/docs/images/09-%E7%82%B9%E5%87%BB%E5%A4%8D%E5%88%B6%E5%AF%86%E9%92%A5.png)

> ⚠️ 密钥就像密码，不要发给别人、不要截图到群里。

## 第三步：安装插件（两种方式选一种）

在 dsh 左边点「Plugins」，再点右上角「+ Add plugin」。

![插件列表](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.4/docs/images/10-%E6%8F%92%E4%BB%B6%E5%88%97%E8%A1%A8.png)

### 方式 A：从 GitHub 安装（推荐，最省事）

在弹出的框里粘贴下面这个地址，点「Install」：

```
https://github.com/snakejohn/dsh-hindsight-local
```

![从 GitHub 安装](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.4/docs/images/11-%E4%BB%8EGitHub%E5%AE%89%E8%A3%85.png)

### 方式 B：下载 zip，从本地文件夹安装（网络连不上 GitHub 时用）

1. 打开 [https://github.com/snakejohn/dsh-hindsight-local/releases](https://github.com/snakejohn/dsh-hindsight-local/releases)，下载最新版本里的 `dsh-hindsight-local-v版本号.zip`（如 `dsh-hindsight-local-v0.1.4.zip`）。
2. 右键 →「全部解压缩」，记住解压出来的文件夹在哪（比如“下载”文件夹里）。
3. 在「Add plugin」框里填这个文件夹的完整路径，点「Install」。

   > 小技巧（Windows）：在资源管理器里打开那个文件夹，点一下顶部地址栏，复制里面的路径就行。

![从本地文件夹安装](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.4/docs/images/12-%E4%BB%8E%E6%9C%AC%E5%9C%B0%E6%96%87%E4%BB%B6%E5%A4%B9%E5%AE%89%E8%A3%85.png)

装好后，在「Installed plugins」里能看到 **dsh-hindsight-memory**，确认右边的开关是打开的。

## 第四步：首次设置（真的只有三步）

装好后，左下角会多出一个小卡片，显示 **⚪ 需要设置**，点它就进入设置页。

![侧栏-需要设置](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.4/docs/images/13-%E4%BE%A7%E6%A0%8F-%E9%9C%80%E8%A6%81%E8%AE%BE%E7%BD%AE.png)

![三步设置页](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.4/docs/images/14-%E4%B8%89%E6%AD%A5%E8%AE%BE%E7%BD%AE%E9%A1%B5.png)

刚装好时，密钥下面会写 **「未设置」**；「整理记忆的模型」默认写着 **「和 dsh 用同一个 · 使用 dsh 的密钥」**。

1. **① 选服务商**：已经帮你选好了“硅基流动”，不用动。
2. **② 粘贴密钥**：把第二步复制的密钥粘进去（会显示成一串圆点）。等一两秒，它会**自动检查**，出现绿色的「密钥可以用 ✓」就对了。同时会出现「正在获取模型…」，随后多出 **「理解文字的模型」** 和 **「排序模型」** 两个选择器，下面写着「共 N 个可选模型」。默认的 `BAAI/bge-m3` 和 `BAAI/bge-reranker-v2-m3` 就很好，不用改。

   ![密钥检测通过](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.4/docs/images/15-%E5%AF%86%E9%92%A5%E6%A3%80%E6%B5%8B%E9%80%9A%E8%BF%87.png)

   如果显示“密钥不对”，回硅基流动重新复制一次完整的密钥（`sk-` 开头那一整串，别带空格）。如果显示“网络不通”，检查一下网络再试。

3. **「整理记忆的模型」**：它负责把聊天内容整理成一条条好找的记忆。默认**和 dsh 用同一个模型**（比如 DeepSeek）。插件拿不到 dsh 自己存的密钥，所以这里可以把那个模型的密钥也粘一次；**不粘也能用**，只是先保存原话、不做整理。
4. **③ 一键开始**：点它。

## 第五步：一键部署（等它自己弄好）

点完「一键开始」，插件会自己完成所有准备：下载运行环境（电脑上没有 Python 也没关系，会自动下载）、下载记忆程序、启动、检查。默认走国内镜像，第一次大约 **3–10 分钟**，之后再开 dsh 只要几秒钟。

## 第六步：日常使用

### 1. 正常聊天就行

部署好以后，**像平时一样聊天**。插件会在后台自己记，下次聊天时自己想起来。

试一试：今天告诉它「我早上 7 点去跑步了」，明天新开一个对话问「我昨天早上干了啥？」，它就能答上来。

### 2. 要不要导入以前的对话（可选）

装好后插件**只自动记新聊天**。设置页会问「**要导入以前的对话吗？**」：

![导入以前的对话](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.4/docs/images/39-%E5%AF%BC%E5%85%A5%E4%BB%A5%E5%89%8D%E7%9A%84%E5%AF%B9%E8%AF%9D.png)

- 想导入：点「去选择」，勾一个工作区，或者点「选择单个对话」挑几段，再点「记住」。会一段一段慢慢整理，记过的不会重复。
- 不想导入：点「不用了」。

### 3. 看左下角小卡片

| 颜色 | 文字 | 你要做什么 |
|---|---|---|
| 🟢 | 记忆正常 | 啥也不用管 |
| 🟡 | 正在准备 / 模型被限流 | 等一会儿，要记的内容不会丢 |
| 🟡 | 模型地址连不上 | 打开你给 dsh 用的那个本机模型程序，连上后自动继续 |
| 🟡 | N 段没整理好 | 会自动重试；也可以去「状态」页点「重试失败项」 |
| ⚪ | 需要设置 | 点它，去填密钥 |
| 🔴 | 出问题了 | 点它看原因，一般点「重试」就好 |

### 4. 看看它记住了什么

点左下角的小卡片，就会打开控制面板（「状态」页）。

![控制面板总览](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.4/docs/images/25-%E6%8E%A7%E5%88%B6%E9%9D%A2%E6%9D%BF%E6%80%BB%E8%A7%88.png)

- 「记忆服务」写着 **ready**，就说明一切正常。
- 「看看记住了什么」：默认收起，点「展开看看」先显示最新 10 条，「加载更多」继续看，也能搜索、换记忆库；打开「隐藏内容」后文字变模糊，点一下才显示，开关会一直记住。

![按记忆库浏览](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.4/docs/images/29-%E6%8C%89%E8%AE%B0%E5%BF%86%E5%BA%93%E6%B5%8F%E8%A7%88.png)

- 「搜索记忆」：输入关键词（比如「跑步」），按回车就能找到。

![搜索记忆](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.4/docs/images/30-%E6%90%9C%E7%B4%A2%E8%AE%B0%E5%BF%86.png)

卡住了？在「状态」页点「重新启动」；还不行就点「重新安装」。

### 5. 想少记点或多记点（可选）

「高级设置 → 记住哪些内容」里每项一个开关：默认只记「我说的话」和「AI 的回复」；工具调用、AI 的思考过程、系统提示、已归档的对话、子代理的对话默认都不记，需要再打开；「最短字数」默认 24。插件自己插进对话的记忆永远不会再记一遍。改了只影响以后新记的内容。

## 第七步：备份和迁移记忆（换电脑也不丢）

记忆都存在**你自己的电脑上**。备份就是把几个文件夹复制走，恢复就是放回原位。

### 1. 记忆存在哪

| 内容 | Windows | Mac / Linux |
|---|---|---|
| 记忆本身（最重要） | `C:\Users\你的用户名\.pg0\instances\dsh-hindsight\` | `~/.pg0/instances/dsh-hindsight/` |
| 记录哪些对话已记过 | `C:\Users\你的用户名\.dsh-hindsight\` | `~/.dsh-hindsight/` |
| 插件设置（含密钥） | 插件文件夹里的 `.env` | 插件文件夹里的 `.env` |

> 插件文件夹一般在 `用户目录/.dsh/profiles/default/node_modules/dsh-hindsight-memory/`。
> Windows / Mac 的位置作者还没在真机上确认过，找不到的话欢迎提 issue。

### 2. 备份

1. **完全退出 dsh**（不是最小化）。正在运行时复制，备份可能是坏的。
2. 浏览器打开 `http://127.0.0.1:8888/health`，**打不开**就说明已经停好了。
3. 把上面三样复制到 U 盘或网盘。`.dsh-hindsight` 里的 `venv` 文件夹很大，可以不要，丢了插件会重新下载。

> ⚠️ `.env` 里有你的密钥，别发给别人、别传到公开的地方。

### 3. 换新电脑 / 重装系统后恢复

1. 新电脑上按前面的步骤装好 dsh 和插件，**先别聊天**，然后完全退出 dsh。
2. 把备份的文件夹和 `.env` 放回**一样的位置**（覆盖掉）。
3. 打开 dsh，等小卡片变绿。
4. 打开控制面板，看看记忆条数是不是和以前一样。

> 在同一台电脑上「备份 → 删掉 → 放回」实测过，记忆一条不少。跨两台电脑的完整流程作者还没实测，**旧电脑上的数据先别删**。

## 常见问题

**Q：要花钱吗？**
A：插件免费。默认的两个硅基流动模型也免费；“整理记忆的模型”默认用 dsh 的那个，按你那边的计费。

**Q：一直显示“正在准备”？**
A：第一次要下载几百 MB，网速慢会久一点。超过 20 分钟，去「状态」页点「重新安装」。

**Q：老是“没整理好”/被限流？**
A：免费模型和中转程序一次来太多会拒绝。保持「高级设置 → 同时处理数」为 1；还不行就把「整理记忆的模型」改成「自定义 → 硅基流动」，用第二步的密钥，然后点「重试失败项」。

**Q：怎么反馈问题？**
A：插件「状态」页最下面点「**导出日志**」（密钥会自动隐藏），再点「**去提问题**」，把导出的文件拖进表单的「日志」框提交就行：[https://github.com/snakejohn/dsh-hindsight-local/issues](https://github.com/snakejohn/dsh-hindsight-local/issues)
