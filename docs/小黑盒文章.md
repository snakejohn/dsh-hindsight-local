# 给 dsh 装上长期记忆：dsh-hindsight-local 小白教程

## 第一步：打开你的 dsh

我用的是 web 版的（特地独立装了一个干净的），桌面版也一样。

![dsh 主界面](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.5/docs/article-img/01.png)

## 第二步：准备一个硅基流动的密钥

插件需要两个“帮手模型”：一个理解文字，一个给找回来的记忆排序。我这里用的是硅基流动的，两个都免费，而且一个密钥就够了。

- 理解文字的模型（Embedding）：硅基流动 BAAI/bge-m3
- 排序的模型（Reranker）：硅基流动 BAAI/bge-reranker-v2-m3

1. 打开硅基流动官网：[https://cloud.siliconflow.cn](https://cloud.siliconflow.cn) ，注册 / 登录。

![硅基流动登录](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.5/docs/article-img/02.png)

2. 这两个模型都是免费的，不用额外开通：

![bge-m3 免费](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.5/docs/article-img/03.png)

![bge-reranker 免费](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.5/docs/article-img/04.png)

3. 左边点「API 密钥」：

![API 密钥入口](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.5/docs/article-img/06.png)

4. 点「新建 API 密钥」，描述随便写，点「新建密钥」：

![新建密钥](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.5/docs/article-img/07.png)

![创建成功](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.5/docs/article-img/08.png)

5. 点一下密钥那一栏就复制好了（也许需要先实名认证，我认证过了）。复制好后先存起来，后面马上要用。

![点击复制](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.5/docs/article-img/09.png)

## 第三步：安装插件（两种方式选一种）

在 dsh 左边点「Plugins」，再点右上角「+ Add plugin」。

![插件列表](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.5/docs/article-img/10.png)

### 方式 A：从 GitHub 安装（推荐，最省事）

在弹出的框里粘贴下面这个地址，点「Install」：

仓库地址：https://github.com/snakejohn/dsh-hindsight-local

![从 GitHub 安装](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.5/docs/article-img/11.png)

### 方式 B：下载 zip，从本地文件夹安装（网络连不上 GitHub 时用）

1. 打开 [插件仓库](https://github.com/snakejohn/dsh-hindsight-local/releases) （https://github.com/snakejohn/dsh-hindsight-local/releases ），下载最新版本里的 dsh-hindsight-local-v版本号.zip（如 dsh-hindsight-local-v0.1.4.zip）。
2. 右键 →「全部解压缩」，记住解压出来的文件夹在哪（比如“下载”文件夹里）。
3. 在「Add plugin」框里填这个文件夹的完整路径，点「Install」。

> 小技巧（Windows）：在资源管理器里打开那个文件夹，点一下顶部地址栏，复制里面的路径就行。

![从本地文件夹安装](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.5/docs/article-img/12.png)

装好后，在「Installed plugins」里能看到 **dsh-hindsight-memory**，确认右边的开关是打开的。

## 第四步：首次设置（真的只有三步）

装好后，左下角会多出一个小卡片，显示 **⚪ 需要设置**，点它就进入设置页。

![侧栏-需要设置](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.5/docs/article-img/13.png)

![三步设置页](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.5/docs/article-img/14.png)

刚装好时，密钥下面会写 **「未设置」**；「整理记忆的模型」默认写着 **「和 dsh 用同一个 · 使用 dsh 的密钥」**。

1. **① 选服务商**：已经帮你选好了“硅基流动”，不用动。
2. **② 粘贴密钥**：把第二步复制的密钥粘进去（会显示成一串圆点）。等一两秒，它会**自动检查**，出现绿色的「密钥可以用 ✓」就对了。同时会出现「正在获取模型…」，随后多出 **「理解文字的模型」** 和 **「排序模型」** 两个选择器，下面写着「共 N 个可选模型」。默认的 「BAAI/bge-m3」 和 「BAAI/bge-reranker-v2-m3」 就很好，不用改。

![密钥检测通过](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.5/docs/article-img/15.png)

如果显示“密钥不对”，回硅基流动重新复制一次完整的密钥（「sk-」 开头那一整串，别带空格）。如果显示“网络不通”，检查一下网络再试。

3. **「整理记忆的模型」**：它负责把聊天内容整理成一条条好找的记忆。默认**和 dsh 用同一个模型**（比如 DeepSeek）。插件拿不到 dsh 自己存的密钥，所以这里可以把那个模型的密钥也粘一次；**不粘也能用**，只是先保存原话、不做整理。
4. **③ 一键开始**：点它。

## 第五步：一键部署（等它自己弄好）

点完「一键开始」，插件会自己完成所有准备：下载运行环境（电脑上没有 Python 也没关系，会自动下载）、下载记忆程序、启动、检查。默认走国内镜像，第一次大约 **3–10 分钟**，之后再开 dsh 只要几秒钟。

## 第六步：日常使用

### 1. 正常聊天就行

部署好以后，**像平时一样聊天**。插件会在后台自己记，下次聊天时自己想起来。

试一试：今天告诉它「我早上 7 点去跑步了」，明天新开一个对话问「我昨天早上干了啥？」，它就能答上来。

### 2. 要不要导入以前的对话（可选）

装好后插件**只自动记新聊天**。设置页会问「**要导入以前的对话吗？**」：

![导入以前的对话](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.5/docs/article-img/39.png)

- 想导入：点「去选择」，勾一个工作区，或者点「选择单个对话」挑几段，再点「记住」。会一段一段慢慢整理，记过的不会重复。
- 不想导入：点「不用了」。

### 3. 看左下角小卡片

![左下角小卡片的颜色：颜色 / 文字 / 你要做什么](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.5/docs/article-img/table-status.png)

### 4. 看看它记住了什么

点左下角的小卡片，就会打开控制面板（「状态」页）。

![控制面板总览](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.5/docs/article-img/25.png)

- 「记忆服务」写着 **ready**，就说明一切正常。
- 「看看记住了什么」：默认收起，点「展开看看」先显示最新 10 条，「加载更多」继续看，也能搜索、换记忆库；打开「隐藏内容」后文字变模糊，点一下才显示，开关会一直记住。

![按记忆库浏览](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.5/docs/article-img/29.png)

- 「搜索记忆」：输入关键词（比如「跑步」），按回车就能找到。

![搜索记忆](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.5/docs/article-img/30.png)

卡住了？在「状态」页点「重新启动」；还不行就点「重新安装」。

### 5. 想少记点或多记点（可选）

「高级设置 → 记住哪些内容」里每项一个开关：默认只记「我说的话」和「AI 的回复」；工具调用、AI 的思考过程、系统提示、已归档的对话、子代理的对话默认都不记，需要再打开；「最短字数」默认 24。插件自己插进对话的记忆永远不会再记一遍。改了只影响以后新记的内容。

## 第七步：备份和迁移记忆（换电脑也不丢）

记忆都存在**你自己的电脑上**。备份就是把几个文件夹复制走，恢复就是放回原位。

### 1. 记忆存在哪

![记忆存在哪：内容 / Windows / Mac·Linux](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.5/docs/article-img/table-storage.png)

> 插件文件夹一般在 「用户目录/.dsh/profiles/default/node_modules/dsh-hindsight-memory/」。
> Windows / Mac 的位置作者还没在真机上确认过，找不到的话欢迎提 issue。

### 2. 备份

1. **完全退出 dsh**（不是最小化）。正在运行时复制，备份可能是坏的。
2. 浏览器打开 「http://127.0.0.1:8888/health」，**打不开**就说明已经停好了。
3. 把上面三样复制到 U 盘或网盘。「.dsh-hindsight」 里的 「venv」 文件夹很大，可以不要，丢了插件会重新下载。

> ⚠️ 「.env」 里有你的密钥，别发给别人、别传到公开的地方。

### 3. 换新电脑 / 重装系统后恢复

1. 新电脑上按前面的步骤装好 dsh 和插件，**先别聊天**，然后完全退出 dsh。
2. 把备份的文件夹和 「.env」 放回**一样的位置**（覆盖掉）。
3. 打开 dsh，等小卡片变绿。
4. 打开控制面板，看看记忆条数是不是和以前一样。

> 在同一台电脑上「备份 → 删掉 → 放回」实测过，记忆一条不少。跨两台电脑的完整流程作者还没实测，**旧电脑上的数据先别删**。

## 常见问题

**Q：要花钱吗？**
A：插件免费。默认的两个硅基流动模型也免费；“整理记忆的模型”默认用 dsh 的那个，按你那边的计费。

**Q：一直显示“正在准备”？**
A：第一次要下载几百 MB，网速慢会久一点。超过 20 分钟，去「状态」页点「重新安装」。

**Q：老是“没整理好”/被限流？**
A：免费模型和中转程序一次来太多会拒绝。保持「高级设置 → 同时处理数」为 1；还不行就把「整理记忆的模型」改成「自定义 → 硅基流动」，用第二步的密钥，然后点「重试失败项」。

**Q：怎么反馈问题？**
A：插件「状态」页最下面点「**导出日志**」（密钥会自动隐藏），再点「**去提问题**」，把导出的文件拖进表单的「日志」框提交就行。提问题的地址：[https://github.com/snakejohn/dsh-hindsight-local/issues](https://github.com/snakejohn/dsh-hindsight-local/issues)
