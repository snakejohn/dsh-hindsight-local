# 给 dsh 装上长期记忆：dsh-hindsight-local 小白教程（v0.1.2）

> 项目地址：[https://github.com/snakejohn/dsh-hindsight-local](https://github.com/snakejohn/dsh-hindsight-local)（觉得有用请点个 ⭐ Star）
> 下载：[https://github.com/snakejohn/dsh-hindsight-local/releases/latest](https://github.com/snakejohn/dsh-hindsight-local/releases/latest)
>
> v0.1.2 更新：全新玻璃风格选择器（可搜索模型）、每个模型单独显示密钥状态和来源、填密钥后自动获取模型、修复 Windows 启动报 `Invalid port`、新增「代理」设置。

> 一句话：装上这个插件，dsh 里的 AI 就能**记住你们聊过的事**，下次聊天会自动想起来。
> 全程不用打开命令行，跟着图一步步点就行。

## 第一步：打开你的 dsh

我用的是 web 版的（特地独立装了一个干净的），桌面版也一样。

![dsh 主界面](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/01-dsh%E4%B8%BB%E7%95%8C%E9%9D%A2.png)

## 第二步：准备一个硅基流动的密钥

插件需要两个“帮手模型”：一个**理解文字**，一个给找回来的记忆**排序**。我选的是硅基流动，两个都免费，而且**一个密钥就够了**（你也可以以后在“高级设置”里换成别家的）。

- 理解文字的模型：硅基流动 `BAAI/bge-m3`
- 排序的模型：硅基流动 `BAAI/bge-reranker-v2-m3`

1. 打开 [https://cloud.siliconflow.cn](https://cloud.siliconflow.cn)，注册 / 登录。

   ![硅基流动登录](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/02-%E7%A1%85%E5%9F%BA%E6%B5%81%E5%8A%A8%E7%99%BB%E5%BD%95.png)

2. 这两个模型都是免费的，不用额外开通：

   ![bge-m3 免费](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/03-bge-m3%E5%85%8D%E8%B4%B9.png)
   ![bge-reranker 免费](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/04-bge-reranker%E5%85%8D%E8%B4%B9.png)

   顺带一提：`XingChenAGI/Xing4.0-29B` 也免费，可以当“整理记忆的模型”备用（插件默认不用它，见后面的说明）。

   ![Xing4.0 免费](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/05-Xing4.0%E5%85%8D%E8%B4%B9.png)

3. 左边点「API 密钥」：

   ![API 密钥入口](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/06-API%E5%AF%86%E9%92%A5%E5%85%A5%E5%8F%A3.png)

4. 点「新建 API 密钥」，描述随便写，点「新建密钥」：

   ![新建密钥](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/07-%E6%96%B0%E5%BB%BA%E5%AF%86%E9%92%A5.png)
   ![创建成功](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/08-%E5%AF%86%E9%92%A5%E5%88%9B%E5%BB%BA%E6%88%90%E5%8A%9F.png)

5. 点一下密钥那一栏就复制好了（也许需要先实名认证，我认证过了）。**复制好后先存起来，后面马上要用。**

   ![点击复制](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/09-%E7%82%B9%E5%87%BB%E5%A4%8D%E5%88%B6%E5%AF%86%E9%92%A5.png)

> ⚠️ 密钥就像密码，不要发给别人、不要截图到群里。

## 第三步：安装插件（两种方式选一种）

在 dsh 左边点「Plugins」，再点右上角「+ Add plugin」。

![插件列表](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/10-%E6%8F%92%E4%BB%B6%E5%88%97%E8%A1%A8.png)

### 方式 A：从 GitHub 安装（推荐，最省事）

在弹出的框里粘贴下面这个地址，点「Install」：

```
https://github.com/snakejohn/dsh-hindsight-local
```

![从 GitHub 安装](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/11-%E4%BB%8EGitHub%E5%AE%89%E8%A3%85.png)

### 方式 B：下载 zip，从本地文件夹安装（网络连不上 GitHub 时用）

1. 打开 [https://github.com/snakejohn/dsh-hindsight-local/releases](https://github.com/snakejohn/dsh-hindsight-local/releases)，下载最新版本里的 `dsh-hindsight-local-v版本号.zip`（如 `dsh-hindsight-local-v0.1.2.zip`）。
2. 右键 →「全部解压缩」，记住解压出来的文件夹在哪（比如“下载”文件夹里）。
3. 在「Add plugin」框里填这个文件夹的完整路径，点「Install」。

   > 小技巧（Windows）：在资源管理器里打开那个文件夹，点一下顶部地址栏，复制里面的路径就行。

![从本地文件夹安装](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/12-%E4%BB%8E%E6%9C%AC%E5%9C%B0%E6%96%87%E4%BB%B6%E5%A4%B9%E5%AE%89%E8%A3%85.png)

装好后，在「Installed plugins」里能看到 **dsh-hindsight-memory**，确认右边的开关是打开的。

## 第四步：首次设置（真的只有三步）

装好后，左下角会多出一个小卡片，显示 **⚪ 需要设置**，点它就进入设置页。

![侧栏-需要设置](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/13-%E4%BE%A7%E6%A0%8F-%E9%9C%80%E8%A6%81%E8%AE%BE%E7%BD%AE.png)

![三步设置页](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/14-%E4%B8%89%E6%AD%A5%E8%AE%BE%E7%BD%AE%E9%A1%B5.png)

刚装好时，密钥下面会写 **「未设置」**；「整理记忆的模型」默认写着 **「和 dsh 用同一个 · 使用 dsh 的密钥」**。

1. **① 选服务商**：已经帮你选好了“硅基流动”，不用动。
2. **② 粘贴密钥**：把第二步复制的密钥粘进去（会显示成一串圆点）。等一两秒，它会**自动检查**，出现绿色的「密钥可以用 ✓」就对了。同时会出现「正在获取模型…」，随后多出 **「理解文字的模型」** 和 **「排序模型」** 两个选择器，下面写着「共 N 个可选模型」。默认的 `BAAI/bge-m3` 和 `BAAI/bge-reranker-v2-m3` 就很好，不用改。

   ![密钥检测通过](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/15-%E5%AF%86%E9%92%A5%E6%A3%80%E6%B5%8B%E9%80%9A%E8%BF%87.png)

   如果显示“密钥不对”，回硅基流动重新复制一次完整的密钥（`sk-` 开头那一整串，别带空格）。如果显示“网络不通”，检查网络或看下面「代理」一节。

3. **「整理记忆的模型」**：它负责把聊天内容整理成一条条好找的记忆。默认**和 dsh 用同一个模型**（比如 DeepSeek）。插件拿不到 dsh 自己存的密钥，所以这里可以把那个模型的密钥也粘一次；**不粘也能用**，只是先保存原话、不做整理。
4. **③ 一键开始**：点它。

## 左下角小卡片的意思

| 颜色 | 文字 | 意思 / 你要做什么 |
|---|---|---|
| 🟢 | 记忆正常 | 一切正常，啥也不用管 |
| 🟡 | 正在准备 | 正在下载或启动，等一会儿 |
| 🟡 | 模型被限流 | 模型太忙或额度用完了。会自动重试，要记的内容已排队**不会丢**；也可以去「高级设置」换个模型 |
| ⚪ | 需要设置 | 还没填密钥，点它去设置 |
| 🔴 | 出问题了 | 点它看「发生了什么 + 怎么做」，一般点「重试」就好 |

卡片上还会写：现在用的是哪个**记忆库**、有几条**等着记住**、**上次记住**和**上次回忆**是什么时候。鼠标放上去能看到完整信息。

## 状态页

点左下角卡片，或在插件页面点上面的「状态」，就能看到：记忆服务是不是正常、准备进度每一步、用了多少内存，以及三个按钮：

- **检查一下**：看看服务通不通。
- **重新启动**：卡住了就点它。
- **重新安装**：反复出错时点它，会重新下载记忆程序。

## 主动记忆（让它现在就记住）

平时它会自动记。如果你想让它**马上**把以前的对话也记住：「设置」→「高级设置」→「现在就记住」：

- **记住这个工作区的对话**：只记你选中的那个工作区。
- **记住全部对话（不含已归档）**：所有没归档的对话都记一遍。

已经记过的内容不会重复记；**归档了的对话不会被记住**。

## 高级设置：换模型、换服务商

一般不用动。需要时点「高级设置（一般不用改）」展开：

![高级设置](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/22-%E9%AB%98%E7%BA%A7%E8%AE%BE%E7%BD%AE.png)

- **理解文字的模型 / 排序模型 / 整理记忆的模型**：三个都可以各自换服务商和模型。点右边蓝色的选项会弹出一个选择器（当前项打勾，可用方向键和回车选，点外面或按 Esc 关闭）。选好服务商，地址会**自动填好**。

  ![服务商选择器](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/35-%E6%9C%8D%E5%8A%A1%E5%95%86%E9%80%89%E6%8B%A9%E5%99%A8.png)

- **模型**：填好密钥约半秒后会自动「正在获取模型…」，只列出这一类能用的模型（比如“理解文字”只列向量模型）。点开后可以**搜索**；列表里没有的，直接输入名字再点「使用「…」」即可。旁边的 ↻ 是重新获取。

  ![模型搜索](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/36-%E6%A8%A1%E5%9E%8B%E6%90%9C%E7%B4%A2.png)

- **API Key**：每个模型各自显示密钥状态：「未设置」，或「已设置（来源：本插件的 .env / dsh 插件配置 / 系统环境变量）」，选“和 dsh 用同一个”时显示「使用 dsh 的密钥」。密钥本身永远不会显示。

  ![密钥来源](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/37-%E5%AF%86%E9%92%A5%E6%9D%A5%E6%BA%90.png)

- 排序模型和整理记忆的模型如果跟“理解文字的模型”是同一家，**密钥留空就会自动共用**。
- 整理记忆的模型有三个选择：**和 dsh 用同一个**（默认）/ **自己指定**（比如选硅基流动的 `XingChenAGI/Xing4.0-29B`）/ **不整理**。
- **记忆库**：默认每个工作区各记各的；也可以让所有工作区共用一个。工作区列表会自动读出来，并显示每个工作区有几个对话（不算已归档的）。

- **代理**（在「本地服务」那一组）：**自动**（默认，跟随系统代理，并自动去掉记忆程序认不出的地址，比如 `[::1]`）/ **不用代理** / **自定义地址**（如 `http://127.0.0.1:7890`）。
- **清除密钥**：一键清掉本插件 `.env` 和 dsh 插件配置里保存的所有密钥（会先让你确认）。系统环境变量里的密钥需要你自己删。

  ![代理设置](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/38-%E4%BB%A3%E7%90%86%E8%AE%BE%E7%BD%AE.png)

改完记得点底部的「保存」。

深色模式下也一样好看：

![深色模式](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/23-%E6%B7%B1%E8%89%B2%E6%A8%A1%E5%BC%8F.png)

## Hindsight 控制面板

控制面板用来查看记忆服务是否正常、记住了多少内容，以及都记住了什么。

> 📷 截图使用 LoCoMo 压测写入的真实记忆数据渲染；界面文案与插件控制面板一致。截图中不含任何密钥。

### 1. 打开控制面板

dsh 左侧栏底部有一张记忆状态小卡片，比如「记忆正常」「1 条待记住」。**点击这张卡片**就能打开控制面板。

也可以从菜单进入：**插件 → dsh-hindsight-memory →「状态」标签页**。

![控制面板入口](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/24-%E6%8E%A7%E5%88%B6%E9%9D%A2%E6%9D%BF%E5%85%A5%E5%8F%A3.png)

![控制面板总览](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/25-%E6%8E%A7%E5%88%B6%E9%9D%A2%E6%9D%BF%E6%80%BB%E8%A7%88.png)

### 2. 看服务是否健康

「记忆服务」区域显示以下信息：

- 运行状态：正常时为 ready；
- Hindsight 版本；
- 服务地址；
- 安装方式；
- 当前使用的模型。如果写着「和 dsh 用同一个模型 ✓」，说明模型已经自动跟随 dsh。

如果这里不是 ready，请先看下面的「没记住的」区域，或者到「设置」页重新部署。

![服务健康](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/26-%E6%9C%8D%E5%8A%A1%E5%81%A5%E5%BA%B7.png)

### 3. 看每个记忆库的数量

「记忆库」列表里每一行是一个记忆库（bank），后面会显示「N 条记忆 / N 段对话」。✗ 表示这个库有写入失败的记录。

![各记忆库数量](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/27-%E5%90%84%E8%AE%B0%E5%BF%86%E5%BA%93%E6%95%B0%E9%87%8F.png)

「记住进度」显示的是后台整理记忆的进度：✓ 表示完成，✗ 表示失败。进度为「完成」时，说明所有对话都已经处理好。

![记住进度](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/28-%E8%AE%B0%E4%BD%8F%E8%BF%9B%E5%BA%A6.png)

### 4. 选择一个记忆库，按时间浏览

在「看看记住了什么」区域，点击右上角的 Bank 名，选择要查看的记忆库。

列表中每条记忆上方会显示「时间 · 类型」（时间为 24 小时制），比如 world、experience、observation，下方是记住的内容。

![按记忆库浏览](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/29-%E6%8C%89%E8%AE%B0%E5%BF%86%E5%BA%93%E6%B5%8F%E8%A7%88.png)

### 5. 搜索记忆

在「搜索记忆」输入框里输入关键词（例如「橘子」），然后按回车，就会列出相关记忆和对应时间。

![搜索记忆](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/30-%E6%90%9C%E7%B4%A2%E8%AE%B0%E5%BF%86.png)

### 6. 最近写入和失败写入

- **最近记住的**：最近交给记忆服务的对话，包括时间、记忆库和轮数。
- **没记住的**：写入失败的记录。正常情况下显示「暂无」。如果这里有内容，一般是模型超时或密钥错误，可以检查「设置」后再重试。

![最近与失败写入](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/31-%E6%9C%80%E8%BF%91%E4%B8%8E%E5%A4%B1%E8%B4%A5%E5%86%99%E5%85%A5.png)

## 迁移和备份记忆

> 下面每一步都在 Linux 上实际做过一遍（2026-10-24，Hindsight 1.1.0）。标「⚠️ 未在真机核实」的是 Windows / Mac 上的对应位置，作者还没有在真机上确认过；标「暂不支持」的是插件目前做不到的。

### 1. 记忆存在哪里

| 内容 | Linux / Mac | Windows（⚠️ 未在真机核实） |
|---|---|---|
| **记忆本身**（数据库，最重要） | `~/.pg0/instances/dsh-hindsight/` | `C:\Users\你的用户名\.pg0\instances\dsh-hindsight\` |
| 服务设置（含密钥、向量维度） | 插件文件夹里的 `.env`，例如 `~/.dsh/profiles/default/node_modules/dsh-hindsight-memory/.env` | `C:\Users\你的用户名\.dsh\profiles\default\node_modules\dsh-hindsight-memory\.env` |
| 哪些对话已经记过（防止重复写） | `~/.dsh-hindsight/state/` | `C:\Users\你的用户名\.dsh-hindsight\state\` |
| 上次成功启动时的向量维度 | `~/.dsh-hindsight/embedding-dim.json` | `C:\Users\你的用户名\.dsh-hindsight\embedding-dim.json` |
| 日志 | `~/.dsh-hindsight/logs/` | `C:\Users\你的用户名\.dsh-hindsight\logs\` |

「哪个工作区用哪个记忆库」这类面板设置保存在 dsh 自己的插件设置里，不在 `.env`。

### 2. 备份（最简单、最稳的方法）

1. **完全退出 dsh**（不是最小化）。插件启动的本地记忆服务会跟着停下——数据库正在运行时复制，备份可能是坏的。
2. 确认服务真的停了：在浏览器打开 `http://127.0.0.1:8888/health`，应该**打不开**。
3. 把下面三样复制到 U 盘或网盘（实测：用下面的命令打包，删掉原数据后解压回原位，8 个记忆库的条数、每条内容和时间一模一样，也没有重复写入）：
   - `~/.pg0/instances/dsh-hindsight/` 整个文件夹
   - `~/.dsh-hindsight/` 整个文件夹（里面的 `venv` 很大，可以不备份，丢了插件会重新下载）
   - 插件文件夹里的 `.env`
4. `.env` 里有你的密钥，**不要发给别人、不要传到公开的地方**。

Linux 上可以用一条命令打包（先退出 dsh）：

```bash
tar czf ~/dsh-记忆备份-$(date +%F).tar.gz -C ~ .pg0/instances/dsh-hindsight .dsh-hindsight/state .dsh-hindsight/embedding-dim.json
```

### 3. 把本地记忆迁移成独立服务

适合：想让记忆服务一直开着（不跟着 dsh 开关），或者以后给多个程序用。实测在同一台电脑上，**直接用原来那份数据**（不用复制）就行。

1. **完全退出 dsh**，确认 `http://127.0.0.1:8888/health` 打不开。
2. 新建一个文件夹，比如 `~/hindsight-server`，把插件文件夹里的 `.env` **复制**进去。
3. 在这个文件夹里新建 `start.sh`，内容如下（Hindsight 程序就用插件已经装好的那份）：

   ```bash
   #!/bin/bash
   # 独立运行 Hindsight（不依赖 dsh）。数据仍在 ~/.pg0/instances/dsh-hindsight
   cd "$(dirname "$0")"
   set -a; . ./.env; set +a
   exec ~/.dsh-hindsight/venv/bin/hindsight-api --host 127.0.0.1 --port "${HINDSIGHT_API_PORT:-8888}"
   ```

4. 运行 `chmod +x start.sh && ./start.sh`，等到浏览器打开 `http://127.0.0.1:8888/health` 显示 `healthy`。
5. 打开 dsh →「插件 → dsh-hindsight-memory」→ 设置，选 **「已经配置好了」**，地址填 `http://127.0.0.1:8888`，保存。
6. 到「状态」页，看到 `ready` 和原来的记忆库就成功了：

![已连接独立服务](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/34-%E5%B7%B2%E8%BF%9E%E6%8E%A5%E7%8B%AC%E7%AB%8B%E6%9C%8D%E5%8A%A1.png)

实测结果：迁移前后两个记忆库的记忆条数（12 条、6 条）、对话数（4、2）和每条记忆的时间完全一致；问「我今天早上7点干了啥？」能找回 07:05 跑步那条；面板浏览、搜索正常；启动补录和「现在就记住」**不会**把已经记过的对话再写一遍。之后退出 dsh，独立服务继续运行——插件在「已经配置好了」模式下**不会**启动、停止或修改这个服务。

注意：
- 独立服务和插件的「本地部署」**不要同时开**：两边会抢同一份数据库和 8888 端口。迁移后插件就一直用「已经配置好了」。
- 想加访问密码：启动前多设两个环境变量 `HINDSIGHT_API_TENANT_EXTENSION=hindsight_api.extensions.builtin.tenant:ApiKeyTenantExtension` 和 `HINDSIGHT_API_TENANT_API_KEY=你自己想的密码`，然后在插件设置的「Hindsight API Key」里填同一个密码。填错时面板会这样提示（实测）：

![密钥不对](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/33-%E5%AF%86%E9%92%A5%E4%B8%8D%E5%AF%B9.png)

- 服务中途停了：卡片会显示「连不上记忆服务」，这期间聊的内容**不会丢**；把服务重新开起来，插件一分钟内会自己连上并把漏掉的对话补记进去（实测约 15～70 秒）。
- 想回到插件自己管理：停掉独立服务，在设置里重新选「本地部署」即可，用的还是同一份数据（实测）。
- 开机自动启动独立服务：暂不提供现成的做法（没有实测）。
- Windows 上的启动脚本：⚠️ 未在真机核实，暂不提供。

### 4. 换新电脑 / 重装系统后找回记忆

1. 在旧电脑上按「2. 备份」做好备份。
2. 新电脑上先按本文前面的步骤装好 dsh 和插件，**先不要开始聊天**，然后完全退出 dsh。
3. 把备份放回**同样的位置**：`~/.pg0/instances/dsh-hindsight/`、`~/.dsh-hindsight/state/`、`~/.dsh-hindsight/embedding-dim.json`，以及插件文件夹里的 `.env`。
4. 打开 dsh，等卡片变绿，到「状态」页看记忆库数量是否和以前一样。

说明：「打包 → 删掉原数据 → 解压回原位 → 打开 dsh」在同一台电脑上实测过，条数和内容完全一致；**跨两台不同电脑**的完整流程作者还没有实测，⚠️ 请先保留好旧电脑上的数据再操作。另外，工作区路径变了（比如新电脑用户名不同）时，插件会按新路径算出新的记忆库名，旧记忆不会自动对上——这时可以在设置里用「工作区 → 记忆库」把新路径指到旧的记忆库名上。

### 5. 合并工作区（多个工作区共用一个记忆库）

1. 设置 →「工作区」，把要合并的几个工作区都选成同一个记忆库（可以选「新建记忆库」起个名字，比如 `dsh-shared`），保存。
2. 之后这些工作区的**新对话**都写进这个共享库，互相能想起来；没有加进来的工作区想不起来（实测）。

⚠️ 重要：**旧记忆不会自动搬过去**。改完之后，旧对话的记忆还留在原来的记忆库里，在共享库里问不到（实测：合并后问「早上7点干了啥」找不到）。启动补录也不会重写已记过的对话。

想把旧对话也写进共享库（实测可行）：
1. 完全退出 dsh。
2. 把 `~/.dsh-hindsight/state/` 文件夹改个名备份（例如 `state.bak`），这一步会让插件「忘记」哪些对话记过。
3. 打开 dsh，启动补录会把所有未归档的对话按**现在的设置**重新写一遍（会花一些模型调用；已归档的对话不会写）。
4. 原来的记忆库原样保留，不会被删除或改动；同一段对话在同一个库里不会出现两份。

### 6. 拆分共享库

把某个工作区在「工作区」设置里改回「不指定」（或指到另一个库），保存即可，之后它的新对话写进自己的库。和合并一样，**已经写进共享库的旧记忆不会搬走**，也不能按工作区从共享库里拆出来——**暂不支持**。如果要让拆出去的工作区带上旧记忆，按上面「想把旧对话也写进共享库」同样的步骤重新补录（它会写进新库，共享库里的那份仍然保留）。

### 7. 向量维度（换模型、迁移前必看）

「向量维度」就是模型把一句话变成多少个数字，在「设置 → 高级设置 → 理解文字的模型 → 向量维度」，默认 **1024**（默认模型 BAAI/bge-m3 就是 1024），一般不用改。

- 记忆库建好后，里面的维度就固定了。**迁移、恢复备份时，向量维度和模型要和原来一样。**
- 插件每次启动本地服务前会检查三样东西：你填的维度、模型实际输出的维度（发一次测试请求）、这个记忆库上次成功启动时的维度。只要有一个对不上，就**不启动服务**，并在面板上写清楚怎么改（实测，已有记忆没有任何改动）：

![向量维度不一致](https://cdn.jsdelivr.net/gh/snakejohn/dsh-hindsight-local@v0.1.2/docs/images/32-%E5%90%91%E9%87%8F%E7%BB%B4%E5%BA%A6%E4%B8%8D%E4%B8%80%E8%87%B4.png)

- 想换成不同维度的模型：要用一个新的空记忆库，旧记忆不能直接转换——**暂不支持**自动转换。
- 「已经配置好了」模式下，维度由那台服务自己管：Hindsight 发现库里的维度和模型不一致时会直接拒绝启动，数据不会被破坏。

## 常见问题

**Q：要花钱吗？**
A：插件免费。默认用的两个硅基流动模型也免费；“整理记忆的模型”默认用 dsh 的那个，按你那边的计费。

**Q：一直显示“正在准备”？**
A：第一次要下载几百 MB，网速慢会久一点。超过 20 分钟，去「状态」页点「重新安装」。

**Q：显示“出问题了：端口被占用”？**
A：有别的程序占了 8888 端口。重启电脑后再试，或在「高级设置 → 端口」换一个数字（比如 8899），保存。

**Q：显示“下载失败 / 网络问题”？**
A：检查能不能上网；开了代理或 VPN 的话先关掉再点「重试」。插件默认用国内镜像。

**Q：显示“密钥不对”？**
A：回硅基流动重新复制完整的密钥，粘贴后等出现「密钥可以用 ✓」。

**Q：显示“模型被限流”？**
A：模型太忙或免费额度用完了。插件会自己隔一会儿重试，要记的内容不会丢。急的话去「高级设置」换一个模型。

**Q：我的聊天会被传到哪里？**
A：记忆存在**你自己电脑上**。为了理解和整理文字，聊天内容会发给你选的模型服务商（默认硅基流动和 dsh 的模型）。

**Q：我的密钥存在哪？安全吗？**
A：存在插件文件夹里的 `.env` 文件和 dsh 的设置里，只在你自己的电脑上；日志里不会出现密钥。别把这个文件发给别人。

**Q：新装的插件为什么显示已设置？**
A：v0.1.2 起每个模型单独判断，只有真的填了密钥才算「已设置」，并写明来源。旧版本把“跟随 dsh 时借用的 dsh 密钥”和“同一家服务商共用的密钥”也算进去了，所以新装也显示已设置——插件本身**不带任何密钥**。如果现在仍显示「已设置（来源：…）」，说明那个地方确实存着密钥：「系统环境变量」指电脑里设了 `DSH_HINDSIGHT_*_API_KEY`；「dsh 插件配置」或「本插件的 .env」可以在「高级设置 → 清除密钥」一键清掉。

**Q：启动报 Invalid port 怎么办？**
A：日志里出现 `httpx.InvalidURL: Invalid port: ':1]'` 之类，是系统代理的“不走代理的地址”里有 `[::1]` 这种记忆程序认不出的写法（Windows 常见）。v0.1.2 起插件会自动去掉这些地址再启动，一般直接点「重试」就好；还不行就到「高级设置 → 代理」选「不用代理」，或填你的代理地址（如 `http://127.0.0.1:7890`），保存后重试。

**Q：出问题想找人帮忙，要发什么？**
A：把这个文件夹里的 `hindsight.log` 和 `install.log` 发过去：
Windows：`C:\Users\你的用户名\.dsh-hindsight\logs\`
Mac / Linux：`~/.dsh-hindsight/logs/`

**Q：Windows / Mac 能用吗？**
A：能装，但作者目前只在 Linux 上完整测试过，Windows / Mac 还没有真机验证。遇到问题欢迎到 GitHub 提 issue：[https://github.com/snakejohn/dsh-hindsight-local/issues](https://github.com/snakejohn/dsh-hindsight-local/issues)
